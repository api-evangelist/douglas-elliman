# Douglas Elliman

> Douglas Elliman Inc. (NYSE: DOUG) is a residential real estate brokerage founded in 1911 and headquartered at 575 Madison Avenue, New York City — roughly 6,000 agents across New York, Florida, California, Texas, Colorado, Massachusetts, Connecticut, Nevada, New Jersey, Vermont, the Mid-Atlantic, France and Monaco, with ~46,000 annual sales and rental transactions. It sits on the SELL side of the real estate value chain as a licensed brokerage and MLS participant: it consumes MLS listing data under IDX and broker agreements rather than originating a syndicated feed.

> API posture: NONE PUBLISHED. Douglas Elliman operates no developer portal, publishes no API documentation, and serves no machine-readable contract of any kind — no OpenAPI, no Swagger, no GraphQL, no AsyncAPI, no OData $metadata, no Postman collection, no SDK, no webhooks. Probed 2026-07-26. This file is generated by API Evangelist from the public record; Douglas Elliman does not publish an llms.txt (https://www.elliman.com/llms.txt returns 404).

## Access

- [No published developer access](https://www.elliman.com/): There is no self-serve signup, no application form, no partner API program and no data-licence page. A third party wanting Douglas Elliman listing data obtains it one layer upstream — from the MLS Douglas Elliman participates in — by joining that MLS or board, signing its IDX or VOW agreement, or buying a reseller feed (Bridge, Trestle, MLS Grid, Spark).
- [api.elliman.com](https://api.elliman.com/): A real, private IIS/ASP.NET host that answers HTTP 403 at its root with no documentation and no anonymous access. It is recorded as evidence of a private surface and is deliberately NOT listed as an API.
- developer.elliman.com, developers.elliman.com and docs.elliman.com resolve HTTP 200 only because of a wildcard DNS/CDN catch-all that redirects to the marketing homepage. None is a developer portal.

## Standards posture

- [RESO membership](https://www.reso.org/membership/): "Douglas Elliman Real Estate" is listed as a RESO Class D member (Brokers, Agents and Appraisers).
- [RESO certified organizations](https://www.reso.org/certificates/): Douglas Elliman is ABSENT. It is a RESO member, not a RESO-certified data provider — no Web API Core certification, no Data Dictionary certification, no Common Format, no UPI.
- [RetsConnector](https://github.com/DouglasElliman/RetsConnector): the company's sole public repository, a fork of a third-party .NET Core RETS client. Consumer-side evidence that Douglas Elliman pulls MLS data in over the legacy RETS transport.
